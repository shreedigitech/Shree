# Vegetable image sources

The product cards use Wikimedia Commons file URLs so the GitHub Pages test build does not need a heavy local image bundle. Verify the current license/attribution requirements before commercial publication.

- Tomato: https://commons.wikimedia.org/wiki/File:Tomato.png
- Potato: https://commons.wikimedia.org/wiki/File:Potato.png
- Carrot: https://commons.wikimedia.org/wiki/File:Karotte.png
- Additional vegetable images follow Wikimedia Commons file paths in `js/site.js`.

The Tomato and Potato sources were checked during preparation; the Potato file is marked CC0 on its Commons page. Tomato.png is listed under CC0 on Commons.

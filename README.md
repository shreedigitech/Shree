# FreshVeggies — GitHub Pages Test + Optional Backend

The `docs/` directory is the GitHub Pages-ready release requested for testing.

It includes:
- FreshVeggies responsive farm-to-home storefront
- Buldhana-only checkout
- 16 vegetable products
- real vegetable PNG/image assets via Wikimedia Commons
- cart and unlimited quantity
- ₹500+ online-payment rule
- COD below ₹500
- customer order profile and delivery tracking
- manager dashboard with dispatch/delivery status updates
- WhatsApp order links
- optional Gmail notifications through EmailJS

For real multi-device operation, use Firebase Firestore/Auth and a serverless backend for payment verification and automatic WhatsApp/Gmail delivery. See `docs/README.md`.
